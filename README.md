## تشغيل الاتصال المحلي بـ SQL Server

توجد شاشة «اتصال قاعدة SQL Server» لاختبار الخادم المحلي وقراءة مخطط قاعدة البيانات (أسماء الجداول والأعمدة فقط). القيم المبدئية المستخرجة من مستندات المستودع هي:

- الخادم: `.\SQLEXPRESS`
- قاعدة البيانات: `GtsDb2026`
- طريقة المصادقة: مصادقة Windows

يمكن تعديل اسم الخادم أو قاعدة البيانات من الشاشة، ثم اختبار الاتصال وحفظ الإعدادات محليًا. زر تصدير المخطط ينشئ تقرير CSV بأسماء الجداول والأعمدة وأنواعها، ولا يصدّر بيانات العملاء أو الفواتير.

**مهم:** النواة المحاسبية التي في هذا الفرع ما زالت تستخدم قاعدة SQLite محلية دائمة في `%LOCALAPPDATA%\AlSaqrAccounting\accounting.db`. شاشة SQL Server الحالية هي أداة إعداد/اختبار وقراءة مخطط فقط؛ لم تُحوّل عمليات الترحيل والمبيعات والمخزون بعد لتكتب على قاعدة `GtsDb2026` القديمة. لا يجوز وصف النظام بأنه متصل بالكامل بتلك القاعدة قبل مطابقة الجداول والحقول والمفاتيح وإجراءات الترحيل القديمة، ثم اختبار القراءة والكتابة في قاعدة اختبار. هذه الخطوة مقصودة لتجنب الكتابة في جداول النظام القديم على نحو قد يفسد بياناته.

## البناء والنشر على Windows

يتطلب .NET 8 SDK أو Visual Studio 2022:
=======
- **تسجيل الدخول والصلاحيات:** إنشاء مدير النظام عند التشغيل الأول، كلمات المرور مجزّأة باستخدام PBKDF2-SHA256 مع ملح عشوائي، وأدوار مدير النظام والمحاسب والعرض فقط.
- **دليل الحسابات:** عرض الحسابات وإضافة الحسابات الفرعية وتفعيلها أو إيقافها، مع حماية حسابات التحكم المستخدمة في الترحيل.
- **القيود اليومية:** قيود متعددة السطور، والتحقق من توازن المدين والدائن، وترحيل القيد وسجل تدقيق؛ لا يُسمح بحذف القيد المرحّل مباشرة.
- **العملاء والموردون:** بيانات الأطراف ووسائل الاتصال والرقم الضريبي، وربط الأرصدة والحركات بالحساب الفرعي.
- **الأصناف والمخزون:** رصيد افتتاحي، سجل حركات المخزون، تقييم المخزون، متوسط تكلفة المشتريات، ومنع البيع عند عدم كفاية الكمية.
- **فواتير البيع والشراء:** تفاصيل متعددة الأصناف، احتساب ضريبة القيمة المضافة، إنشاء القيود المحاسبية وتحديث المخزون داخل معاملة واحدة.
- **مردودات البيع والشراء:** ربط المردود بالفاتورة الأصلية، التحقق من الكميات القابلة للإرجاع، وعكس الأثر المحاسبي والمخزني والضريبي.
- **سندات القبض والصرف:** ترحيل أثر السند على الصندوق أو البنك وذمم الطرف.
- **التقارير:** ميزان المراجعة، الأستاذ العام، الأرباح والخسائر، الميزانية العمومية، ملخص ضريبة القيمة المضافة، سجلات المبيعات والمشتريات والمردودات، تقييم المخزون وحركته وتسوياته، أرصدة العملاء والموردين، سجل السندات، وسجل التدقيق.
- **الإخراج:** تصدير التقارير إلى CSV بترميز UTF-8، ومعاينة وطباعة التقارير والجداول، وإنشاء نسخة احتياطية متسقة من قاعدة البيانات.

### إصدار ملف ترخيص

شغّل PowerShell 7 على جهاز الإصدار، واحتفظ بالمفتاح الخاص خارج GitHub وفي وسيط آمن. استخدم معرّف الجهاز المعروض في شاشة الترخيص:

```powershell
pwsh -File .\\tools\\New-AlSaqrLicense.ps1 -PrivateKeyPath "D:\\secure\\AlSaqr-License-PrivateKey.pem" -Customer "اسم العميل" -MachineId "معرّف-الجهاز" -Days 365 -OutputPath ".\\customer-license.json"
```

الترخيص مرتبط بالجهاز، والحالة المحلية محمية بـ DPAPI على حساب Windows الحالي. هذا حاجز ترخيص محلي عملي وليس بديلًا عن خادم تحقق مركزي أو حماية ضد مهاجم يتحكم بالكامل في الجهاز. كما أن خصم الكاشير يسجل صافي سعر البيع في الفاتورة؛ لا يفصل النظام الخصم في حساب إيراد مستقل حتى الآن.
