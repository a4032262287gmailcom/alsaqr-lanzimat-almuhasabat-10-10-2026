# الصقر — النظام المحاسبي

فرع عمل مستقل: `feature/real-accounting-core-20261013`

تم إعداد هذا المشروع كنظام محاسبي Windows Forms عربي بقاعدة بيانات تشغيلية دائمة، وليس شاشة عرض أو بيانات تجريبية. لم يتم تعديل مستودع `alsaqr-lanzimat-almuhasabat-2026` الأصلي.

## الوحدات المتاحة

- **الدخول وإدارة المستخدمين:** إنشاء مدير النظام عند التشغيل الأول، كلمات المرور مخزنة بتجزئة PBKDF2-SHA256 مع ملح عشوائي، وأدوار مدير/محاسب/عرض فقط.
- **دليل الحسابات:** حسابات تأسيسية، إضافة حسابات فرعية ومنع تعطيل حسابات التحكم المستخدمة في الترحيل.
- **القيود اليومية:** إدخال قيود مدين/دائن متعددة الأسطر، التحقق من التوازن قبل الترحيل، وسجل قيود مُرحلة لا تُحذف أو تُعدل مباشرة.
- **العملاء والموردون:** حفظ بيانات الأطراف وربط القيود الآجلة والسندات بالحساب الفرعي لكل طرف.
- **الأصناف والمخزون:** رصيد افتتاحي بقيد محاسبي، تقييم مخزون، سجل وارد/صادر، والتحقق من كفاية الرصيد عند البيع. تُحسب تكلفة المبيعات بالتكلفة المسجلة ويُحدّث متوسط تكلفة المشتريات.
- **فواتير البيع والشراء:** حفظ تفاصيل الفاتورة والضريبة وتوليد قيد مزدوج وتحديث المخزون وسجل الحركات داخل معاملة قاعدة بيانات واحدة؛ عند فشل جزء منها تتراجع المعاملة كلها.
- **سندات القبض والصرف:** ترحيل أثر السند على الصندوق/البنك وذمم العميل أو المورد مع حفظ مرجع القيد.
- **التقارير:** ميزان المراجعة، الأستاذ العام، الأرباح والخسائر، الميزانية العمومية، ضريبة القيمة المضافة، سجل المبيعات والمشتريات، تقييم/حركة/تسوية المخزون، أرصدة الأطراف الافتتاحية والحركة والختامية، سندات القبض والصرف، وسجل التدقيق.
- **تصدير ونسخ احتياطي:** تصدير نتائج التقارير إلى CSV بترميز UTF-8، وإنشاء نسخة SQLite متسقة عبر آلية النسخ الاحتياطي في المحرك.

## تشغيل النظام على Windows

1. افتح تبويب **Actions** في هذا المستودع واختر آخر تشغيل ناجح لسير العمل **Build AlSaqr Accounting Desktop**.
2. نزّل الأثر `AlSaqr-Accounting-win-x64` وفك الضغط إلى مجلد مستقل.
3. شغّل `AlSaqr.Accounting.exe`.
4. عند أول تشغيل أنشئ اسم المستخدم وكلمة مرور المدير (10 أحرف على الأقل).
5. تُنشأ قاعدة البيانات `accounting.db` تلقائيًا تحت:
   `%LOCALAPPDATA%\AlSaqrAccounting\accounting.db`

لا توجد معاملات أو أسماء عملاء أو فواتير تجريبية. تتم إضافة دليل الحسابات الأساسي فقط كي تكون القيود الأولية قابلة للترحيل.

## البناء محليًا

يتطلب Visual Studio 2022 أو .NET 8 SDK على Windows:

```powershell
dotnet restore AlSaqr.Accounting.csproj -r win-x64
dotnet build AlSaqr.Accounting.csproj -c Release -r win-x64 --no-restore
dotnet publish AlSaqr.Accounting.csproj -c Release -r win-x64 --no-restore -p:SelfContained=true -o artifacts/publish
```

## حدود الاعتماد الحالي

التوافق الكامل مع جميع شاشات وتقارير نظام الصقر القديم **لم يُثبت بعد**. جرد المصدر يضم 724 شاشة محتملة وآلاف الأحداث والدوال، ويحتاج كل تقرير قديم إلى مطابقة مع تعريفاته وحقوله وإجراءاته المخزنة ونتيجة تشغيل فعلية. يغطي هذا الفرع النواة المحاسبية والتقارير المبينة أعلاه؛ ولا يُدّعى أنه نسخة مطابقة لكل شاشة قديمة، أو أنه اختُبر على قاعدة الإنتاج أو اعتمد للاستخدام القانوني/الضريبي دون اختبار وقبول محاسبي.

قبل استخدامه على بيانات حقيقية، اختبر القيود والضريبة والمخزون والأرصدة الافتتاحية على نسخة قاعدة اختبار، واحتفظ بنسخ احتياطية منتظمة. بيانات هذا المشروع مستقلة ولا تتصل تلقائيًا بقاعدة SQL Server الخاصة بالمستودع الأصلي.
