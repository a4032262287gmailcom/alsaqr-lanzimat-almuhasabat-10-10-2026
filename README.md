# الصقر — نظام محاسبي مستقل لسطح المكتب

هذا الفرع مستقل عن المستودع القديم، ومخصص لبناء تطبيق Windows Forms عربي اعتمادًا على تقارير جرد الشاشات والأحداث والصلاحيات الموجودة في المستودع.

## الوحدات المنفذة في هذا الإصدار
- دليل الحسابات مع الإضافة والتعديل وتفعيل الحساب وإيقافه.
- سجل العملاء والموردين وبيانات الهاتف والرقم الضريبي.
- سجل الأصناف مع التكلفة والسعر والضريبة والكمية.
- فواتير بيع وشراء متعددة الأصناف، مع ترحيل محاسبي متوازن.
- تحديث المخزون عند الفواتير، ومتوسط تكلفة مرجح عند الشراء، ومنع البيع عند عدم كفاية الرصيد.
- القيود اليومية اليدوية مع رفض الترحيل إذا لم يتساوَ المدين والدائن.
- سند قبض من عميل وسند صرف لمورد، مع قيد محاسبي مرتبط.
- تقارير ميزان المراجعة، قائمة الدخل، المركز المالي، ضريبة القيمة المضافة، فواتير العملاء والموردين، حركة المخزون، كشف حساب الأطراف، سندات القبض والصرف، سجل المبيعات، سجل المشتريات، ربحية الأصناف، والأستاذ العام.
- تصدير التقارير إلى CSV بترميز UTF-8، وسجل تدقيق للعمليات.
- قاعدة SQLite محلية مستمرة في مجلد بيانات المستخدم.

## مصدر المواصفات
- `التقرير_الرئيسي.txt` يوضح أن الجرد الساكن أحصى 724 شاشة محتملة و6,627 اشتراك حدث و6,327 مرجع صلاحية و10,408 مرجع فتح وتنقل.
- `00_REAL_INTERNAL_UI_DESIGN.txt` يحتوي على تصميم 369 شاشة WinForms مكتشفة، مع كثافة ملحوظة في التقارير والطلبات والحسابات والعقود.
- ملفات `ERP_EventHandlers_*.csv` و`ERP_FunctionInventory_*.csv` و`الشاشات_ومراجع_التشغيل.csv` و`مراجع_الصلاحيات.csv` هي مراجع الربط التي يجب تتبعها عند تنفيذ الوحدات الإضافية.

## حدود الإصدار الحالية
هذه قاعدة تشغيل محاسبية فعلية للوحدات المذكورة أعلاه، لكنها ليست ادعاءً بأن كل شاشات النظام القديم البالغ عددها 724 قد أُعيد تنفيذها. ما زالت وحدات مثل العقود والإيجار والمطاعم والرواتب والنقل والصيانة والفوترة الإلكترونية والفروع بحاجة إلى تنفيذ مستقل وربط واختبار وفق ملفات الجرد. الجرد الساكن وحده لا يثبت أن كل مسار تشغيل قد تم اختباره.

## البناء
يفتح المشروع على Visual Studio 2022 مع .NET 8 SDK وWindows Forms:
`AlSaqr.Accounting.csproj`

تقوم GitHub Actions ببناء المشروع على Windows. لا تُعتبر نسخة قابلة للتوزيع ناجحة حتى تنتهي عملية البناء والنشر دون أخطاء.
