# الصقر — نظام محاسبي مستقل

هذا المستودع مخصص لإعادة بناء نظام محاسبي فعلي انطلاقًا من تقارير جرد الشاشات والأحداث والصلاحيات.
سيكون التطوير على فروع منفصلة، ولن يتم تعديل مستودع `alsaqr-lanzimat-almuhasabat-2026`.

## حالة التأسيس
- لم تُنسخ بيانات العملاء أو القيود أو بيانات الإنتاج.
- لا توجد بيانات معاملات وهمية.
- يعتمد إصدار البداية على قاعدة بيانات محلية مستمرة مع عمليات محاسبية متوازنة وسجل تدقيق.
- توافقه مع جميع الشاشات الـ724 في النظام القديم ليس مستنتجًا من الجرد الساكن وحده؛ ستوثّق الفجوات بدل ادعاء اكتمال غير مختبر.
