# الصقر لأنظمة المحاسبة

فرع تطوير مستقل: `feature/erp-pos-cashier-20261013` داخل مستودع الصقر الحالي.

تطبيق محاسبي مكتبي باللغة العربية باستخدام C# وWindows Forms و.NET 8. جميع نوافذ التطبيق الجديدة تستخدم الهوية النصية الموحدة **الصقر لأنظمة المحاسبة**، من دون إضافة شعار مصوّر.

## الوظائف الحالية في النواة المحاسبية

- تسجيل الدخول وإدارة المستخدمين بأدوار مدير النظام والمحاسب والعرض فقط.
- دليل الحسابات، القيود اليومية متعددة الأسطر، التحقق من توازن المدين والدائن، وسجل القيود المرحلة.
- العملاء والموردون، الأصناف والمخزون، أرصدة افتتاحية، متوسط تكلفة المشتريات، حركات المخزون وتسوياته.
- فواتير البيع والشراء، مردودات البيع والشراء، سندات القبض والصرف.
- تقارير ميزان المراجعة، الأستاذ العام، الأرباح والخسائر، الميزانية العمومية، ضريبة القيمة المضافة، المخزون، الأطراف، والسجل الرقابي.
- تصدير التقارير إلى CSV ونسخ SQLite احتياطي متسق.
- شاشة كاشير Windows: البحث بالاسم/الرمز، مسح باركود USB، سلة البيع، الكمية والسعر، الخصم، الضريبة، النقدي والشبكة والآجل، حساب الباقي، اعتماد البيع وطباعة الإيصال.
- إدارة الباركود من شاشة الأصناف، مع منع تكرار الباركود غير الفارغ.
- إعدادات تجارية وثيمات محفوظة: كحلي وذهبي، فاتح، داكن، وأخضر تجاري.
- ترخيص مقيّد بمعرّف الجهاز وتوقيع ECDSA، طلب تفعيل واستيراد ملف موقع، وتجربة لمدة 30 يومًا.
- أداة إصدار الترخيص للمالك موجودة في `tools/AlSaqr.LicenseIssuer`؛ المفتاح الخاص غير موجود في المستودع.
- تفاصيل التنفيذ وحدود الاتصال بالقاعدة القديمة في [docs/ERP-Enhancements.md](docs/ERP-Enhancements.md).

## إعدادات المنشأة والسمات والترخيص

تُحفظ إعدادات المنشأة والثيمات في ملف محلي، ويدعم التطبيق ترخيص ECDSA P-256 مرتبطًا بالجهاز مع فترة تجربة وطلب تفعيل. أداة إصدار الترخيص: `tools/AlSaqr.LicenseIssuer`. لا تضع المفتاح الخاص داخل المستودع أو حزمة العملاء.

## تشغيل الاتصال المحلي بـ SQL Server

توجد شاشة «اتصال قاعدة SQL Server» لاختبار الخادم المحلي وقراءة مخطط قاعدة البيانات (أسماء الجداول والأعمدة فقط). القيم المبدئية المستخرجة من مستندات المستودع هي:

- الخادم: `.\SQLEXPRESS`
- قاعدة البيانات: `GtsDb2026`
- طريقة المصادقة: مصادقة Windows

يمكن تعديل اسم الخادم أو قاعدة البيانات من الشاشة، ثم اختبار الاتصال وحفظ الإعدادات محليًا. زر تصدير المخطط ينشئ تقرير CSV بأسماء الجداول والأعمدة وأنواعها، ولا يصدّر بيانات العملاء أو الفواتير.

**مهم:** النواة المحاسبية التي في هذا الفرع ما زالت تستخدم قاعدة SQLite محلية دائمة في `%LOCALAPPDATA%\AlSaqrAccounting\accounting.db`. شاشة SQL Server الحالية هي أداة إعداد/اختبار وقراءة مخطط فقط؛ لم تُحوّل عمليات الترحيل والمبيعات والمخزون بعد لتكتب على قاعدة `GtsDb2026` القديمة. لا يجوز وصف النظام بأنه متصل بالكامل بتلك القاعدة قبل مطابقة الجداول والحقول والمفاتيح وإجراءات الترحيل القديمة، ثم اختبار القراءة والكتابة في قاعدة اختبار. هذه الخطوة مقصودة لتجنب الكتابة في جداول النظام القديم على نحو قد يفسد بياناته.

## البناء والنشر على Windows

يتطلب .NET 8 SDK أو Visual Studio 2022:

```powershell
dotnet restore AlSaqr.Accounting.csproj -r win-x64
dotnet build AlSaqr.Accounting.csproj -c Release -r win-x64 --no-restore
dotnet publish AlSaqr.Accounting.csproj -c Release -r win-x64 --no-restore -p:SelfContained=true -o artifacts/publish
```

يمكن تنزيل حزمة Windows بعد نجاح سير العمل **Build AlSaqr Accounting Desktop** من تبويب Actions في GitHub.

## قبل الاستخدام التجاري

اختبر البيع والخصومات والضريبة والباقي والباركود والمردودات وتكلفة المخزون على قاعدة اختبار. توافق جميع وظائف هذا التطبيق مع كل شاشات وتقارير نظام الصقر القديم، وكذلك الربط النهائي بقاعدة SQL Server القديمة، ما زال يحتاج اختبار قبول محاسبي وتشغيلي على قاعدة العميل الفعلية.
