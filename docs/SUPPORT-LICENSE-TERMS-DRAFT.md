## نطاق الترخيص

1. يُرخّص الإصدار المحدد للعميل ولعدد الأجهزة المكتوب في العرض/العقد.
2. يحدد العقد ما إذا كانت الرخصة مؤقتة أو سنوية أو غير ذلك؛ لا تفترض أن دفع ثمن النسخة يعني ترخيصًا دائمًا.
3. ملف تفعيل البرنامج مرتبط بمعرّف الجهاز في آلية الترخيص الحالية، وقد يتطلب النقل أو الاستبدال طلب تفعيل جديدًا.
4. لا يتضمن الترخيص وحده نقل بيانات النظام القديم أو الكتابة في SQL Server أو تكامل ZATCA أو مزامنة متعددة الأجهزة، إلا إذا نص العقد على ذلك بعد تنفيذ واختبار هذه الميزات.

## البيانات والنسخ الاحتياطي

1. قاعدة البيانات الحالية محلية على جهاز العميل في مجلد بيانات المستخدم.
2. يتفق الطرفان على مسؤولية حفظ النسخ الاحتياطية وتواترها ومكان تخزينها وآلية اختبار الاستعادة.
3. لا يسلم العميل كلمات المرور أو المفتاح الخاص للناشر، ولا يحتوي التثبيت على مفتاح التوقيع الخاص.
4. يُحدد العقد مسؤولية حماية الجهاز وحسابات Windows وصلاحيات المستخدمين ووسائط النسخ الاحتياطي.
