# دليل تثبيت وتشغيل الصقر لأنظمة المحاسبة على Windows

## قبل التثبيت

- النسخة المستهدفة حاليًا Windows x64.
- ثبّت البرنامج من حزمة إصدار منشورة في GitHub Releases، ولا تعتمد على ملفات بناء تجريبية أو مجلد المصدر.
- تحقّق من اسم الإصدار وتاريخ النشر وبصمة SHA-256 التي يزوّدك بها الناشر.
- إذا ظهر تحذير Windows SmartScreen، فلا تتجاوزه تلقائيًا؛ تحقق من مصدر الملف. المثبت لا يكون موقعًا رقميًا ما لم يعلن الإصدار وجود توقيع صالح.
- احتفظ بنسخة احتياطية قبل ترقية نسخة موجودة.

## التثبيت

1. شغّل AlSaqrAccountingSetup-<version>-win-x64.exe بصلاحية تثبيت Windows.
2. اختر لغة المثبت ومجلد البرنامج، ثم أكمل التثبيت.
3. اختر إنشاء اختصار سطح المكتب إن رغبت.
4. شغّل «الصقر لأنظمة المحاسبة» من قائمة Start أو الاختصار.
5. سجّل الدخول أو أكمل الإعداد الأولي وفق شاشة البرنامج؛ لا تفترض وجود كلمة مرور افتراضية.
6. افتح الإعدادات وأدخل البيانات الفعلية للمنشأة والرقم الضريبي والعنوان والهاتف وتفضيلات الطباعة.
7. اضبط طابعة الإيصالات وعرض الورق، ثم اطبع إيصال اختبار قبل الاستخدام.
8. أنشئ بيانات اختبار ونفّذ نموذج اختبار القبول قبل إدخال بيانات إنتاج.

## أين تُحفظ البيانات؟

قاعدة البيانات المحلية الأساسية:

%LOCALAPPDATA%/AlSaqrAccounting/accounting.db

ملف إعدادات المنشأة والثيم والطباعة:

%LOCALAPPDATA%/AlSaqrAccounting/app-settings.json

ويحفظ الترخيص وسجل التجربة في ملفات منفصلة داخل مجلد التطبيق المحلي. لذلك لا تفترض أن نسخ مجلد البرنامج الموجود داخل Program Files وحده نسخة احتياطية كاملة.

## الترخيص

1. افتح شاشة الترخيص داخل التطبيق.
2. أنشئ طلب تفعيل للجهاز واحفظه وأرسله للجهة الموردة عبر قناة آمنة.
3. يراجع المورد اسم الجهة ومعرّف الجهاز وصلاحية الطلب، ثم يصدر ملف الترخيص الموقّع.
4. استورد الملف من شاشة التفعيل وتحقق من حالة الترخيص وتاريخ الانتهاء.
5. احتفظ بنسخة من ملف الترخيص مع مستندات العميل. ملف الترخيص مرتبط بمعرّف الجهاز وقد يتطلب تغيير الجهاز إصدار ملف آخر.

لا يرسل العميل المفتاح الخاص؛ مفتاح التوقيع الخاص بالناشر لا يدخل في التطبيق أو حزمة التثبيت. لا تشارك ملف طلب التفعيل علنًا لأنه يتضمن معرّف جهاز.

## النسخ الاحتياطي والاستعادة

- استخدم زر النسخ الاحتياطي داخل البرنامج واختر قرصًا منفصلًا أو وحدة تخزين آمنة.
- احتفظ بنسخة خارج الجهاز؛ النسخة على القرص نفسه لا تحمي من تعطل القرص أو سرقته.
- جرّب الاستعادة على جهاز أو مجلد اختبار، ولا تستبدل قاعدة إنتاج مباشرة قبل حفظ نسخة منها.
- لا تعتمد على إزالة البرنامج لتكون نسخة احتياطية أو لإدارة بيانات العميل.
- لا يوجد في هذه النسخة إثبات على مزامنة تلقائية خارج الجهاز أو جدولة نسخ احتياطي تلقائي.

## حدود التشغيل الحالية

- قاعدة البيانات المحاسبية محلية SQLite على الجهاز.
- شاشة SQL Server الحالية لا تنقل المعاملات إلى قاعدة GtsDb2026 القديمة؛ وظيفتها اختبار الاتصال واستعراض المخطط.
- لا يُعتمد النظام لإصدار فواتير ضريبية متوافقة مع ZATCA قبل تقديم إثبات فني موثق.
- اختبار البناء الآلي لا يغني عن تجربة قارئ الباركود والطابعة الحقيقية وشاشة القبول.

## عند نقل النظام إلى جهاز جديد

1. أوقف الإدخال على الجهاز القديم.
2. خذ نسخة احتياطية جديدة وتحقق من الملف.
3. ثبّت الإصدار المتوافق على الجهاز الجديد.
4. استعد البيانات بإجراء موثق ومختبر، ثم طابق أرصدة الأستاذ والمخزون.
5. اطلب تفعيلًا جديدًا إذا كان الترخيص مرتبطًا بالجهاز القديم.
6. لا تستخدم الجهازين للإدخال في قاعدتين منفصلتين على أنهما قاعدة مشتركة؛ لا توجد مزامنة تلقائية.
