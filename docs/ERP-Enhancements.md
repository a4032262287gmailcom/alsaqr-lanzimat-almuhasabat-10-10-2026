# ملخص إضافات خالد للأنظمة المحاسبية

فرع التغييرات: `feature/erp-pos-cashier-20261013`

## أضيف في هذا الفرع

- شاشة كاشير مكتبية متصلة بخدمة الفواتير الحالية: بحث أصناف، إدخال باركود، سلة مبيعات، كميات وأسعار، خصم، ضريبة، نقدي/شبكة/آجل، الباقي، ترحيل وطباعة إيصال.
- حقول باركود جديدة للأصناف مع ترحيل آمن لمخطط SQLite المحلي وفهرس يمنع تكرار الباركود.
- دعم في خدمة المحاسبة لحفظ خصم المبيعات وطريقة الدفع والمبلغ المستلم والباقي، مع قيد مزدوج وتحديث المخزون في المعاملة نفسها.
- شاشة اتصال محلي بـ SQL Server بإعداد مبدئي `.\SQLEXPRESS / GtsDb2026` ومصادقة Windows، واختبار اتصال، وفحص أسماء الجداول والأعمدة وأنواعها، وتصدير المخطط إلى CSV.
- إعدادات تجارية محلية تشمل بيانات المنشأة والرقم الضريبي والهاتف والعنوان وتذييل الإيصال وضريبة افتراضية ومجلد النسخ الاحتياطي.
- أربعة ثيمات محفوظة: كحلي وذهبي، فاتح، داكن، وأخضر تجاري.
- ترخيص مرتبط بمعرّف الجهاز بتوقيع ECDSA P-256/SHA-256، طلب تفعيل غير متصل، استيراد ملف مرخص موقع، وفترة تجريبية 30 يومًا مخزنة باستخدام DPAPI.
- أداة مستقلة لإصدار التراخيص داخل `tools/AlSaqr.LicenseIssuer`. لا يوجد المفتاح الخاص في ملفات Git.

## أين تحفظ الإعدادات؟

- قاعدة SQLite: `%LOCALAPPDATA%\AlSaqrAccounting\accounting.db`
- إعدادات الثيم والمنشأة: `%LOCALAPPDATA%\AlSaqrAccounting\app-settings.json`
- ملف الترخيص: `%LOCALAPPDATA%\AlSaqrAccounting\license.json`
- سجل الفترة التجريبية المحمي بـ DPAPI: `%LOCALAPPDATA%\AlSaqrAccounting\trial.bin`
- إعداد SQL Server المحلي: `%LOCALAPPDATA%\AlSaqrAccounting\sqlserver-settings.json`

## حد مهم بخصوص قاعدة البيانات القديمة

شاشة SQL Server الجديدة تختبر الاتصال وتقرأ المخطط فقط. خدمات المحاسبة والكاشير ما زالت تستخدم SQLite المحلية، ولم يتم تحويل جميع عمليات الترحيل إلى قاعدة `GtsDb2026` القديمة. هذا التحويل يجب أن يطابق الجداول والعلاقات والإجراءات المخزنة الحقيقية ويُختبر على نسخة منفصلة قبل تمكين الكتابة حتى لا تتلف أرصدة أو فواتير قائمة.

## تحقق البناء

سير عمل Windows يبني تطبيق سطح المكتب، يشغل اختبارات المحاسبة الحالية، ويبني أداة إصدار الترخيص. يجب أن تكون نتيجة أحدث تشغيل ناجحة قبل نشر أي نسخة على جهاز أو استخدامها تجاريًا.
