# تعريف المنتج — الصقر لأنظمة المحاسبة

برنامج مكتبي عربي يعمل على Windows لإدارة حسابات المنشأة وعمليات البيع والشراء والمخزون والتقارير، مع شاشة نقطة بيع لقارئ باركود USB وطباعة الإيصالات الحرارية.

## الوحدات الموجودة

- الحسابات ودليل الحسابات والقيود اليومية.
- العملاء والموردون والأصناف.
- فواتير البيع والشراء ومردوداتها وسندات القبض والصرف.
- نقطة بيع تتضمن البحث عن الأصناف والكمية والسعر والخصم والضريبة ووسائل الدفع والباقي.
- المخزون والتسويات وحركاته، وسجل الأصول الثابتة والإهلاك بالقسط الثابت.
- تقارير الأستاذ العام وميزان المراجعة والأرباح والخسائر والميزانية والضريبة والمخزون والأطراف.
- إعدادات المنشأة والطابعة والثيمات، وحفظ البيانات في قاعدة محلية ونسخ احتياطي.

## حدود يجب الإفصاح عنها

- هذا إصدار Windows مكتبي، وقاعدة البيانات الأساسية محلية على الجهاز.
- لا توجد مزامنة تلقائية بين الأجهزة أو فروع متعددة على قاعدة مشتركة.
- شاشة إعداد اتصال SQL Server تختبر الاتصال وتقرأ مخطط قاعدة البيانات فقط، ولا ترحل العمليات المحاسبية إلى قاعدة GtsDb2026 القديمة.
- لم يثبت توافق الفوترة الإلكترونية السعودية للنسخة الحالية.
- بعض إجراءات شاشة إدخال المشتريات والمبيعات غير مفعّلة؛ تُراجع وثيقة الشاشة ونموذج القبول قبل عرض هذه الواجهة للعميل.
- المثبت المضاف إلى المستودع يحتاج تشغيلًا ناجحًا في CI واختبار تثبيت على جهاز نظيف قبل تسليمه.
- مدة الترخيص وخطة الدعم والسعر يجب أن تُذكر كتابةً في العرض والعقد.

## تحديد ملاءمة العميل

قبل التسعير، اسأل العميل عن نظام التشغيل، وعدد الأجهزة، وطريقة النسخ الاحتياطي، والطابعة، وقارئ الباركود، وحاجة الفوترة الإلكترونية، والحاجة إلى ترحيل بيانات نظام سابق أو اتصال شبكة. لا تبع ميزة خارج النطاق المختبر على أنها متاحة.
